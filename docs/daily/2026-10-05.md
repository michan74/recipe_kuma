## 判明: Cloud Run からは YouTube をダウンロードできない

- 実動画で試すと yt-dlp が失敗:
  `Sign in to confirm you're not a bot. Use --cookies-from-browser or --cookies ...`
- 原因は **データセンターIPであること** による bot 判定。ローカルで動くのは家庭回線のIPだから。
  - **固定IP（Cloud NAT / AWSのElastic IP相当）では解決しない**。IPが変わることではなく、IP帯がデータセンターであることで弾かれている。
  - **AWS 等の他クラウドでも同じ**。
- 画面のエラーメッセージ「非公開・年齢制限・URLの誤り」は実際の原因と違い、誤解を招く（bot判定は別メッセージにすべき）。

### 検討した対策

| 案 | 評価 |
|---|---|
| cookie（捨てアカウント）を yt-dlp に渡す | 無料・実装小。アカウントBAN／cookie失効のリスク。採用するならまずこれ |
| 住宅用プロキシ | 有料（デモ規模なら数ドル見込み）・実装小。cookieがダメなら次点 |
| Gemini に YouTube URL を直接渡す | ダウンロード不要・URL入力は無料（プレビュー、公開動画のみ、無料枠8時間/日）。ただしクリップ・fps指定不可で、何を見たか追えず**再現性・調整性が落ちる**ため見送り |
| 動画ファイルのアップロード入口 | 既存パイプラインがそのまま動く。YouTubeショートは保存しづらく補助的 |
| PO Token プラグイン（bgutil） | データセンターIPでは効かないことが多く後回し |
